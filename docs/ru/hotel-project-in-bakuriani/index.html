Проект гостиницы, Бакуриани

Проект гостиницы для Бакуриани, горнолыжного курорта в центральной Грузии. Цоколь из бутового камня несёт деревянные балконы и крутую кровлю, прорезанную рядами треугольных слуховых окон; вход отмечен остеклённым фронтоном на открытых деревянных фермах.
